## 🌐 部署说明

### GitHub Pages 部署步骤

1. **创建 GitHub 仓库**
   ```bash
   # 仓库名：adamlei 或 adamlei-profile
   # 可见性：Public
   ```

2. **推送文件到 GitHub**
   ```bash
   git init
   git add index.html README.md
   git commit -m "Initial commit - Adam Lei professional profile"
   git branch -M main
   git remote add origin https://github.com/adamlei/adamlei.git
   git push -u origin main
   ```

3. **启用 GitHub Pages**
   - 进入仓库 Settings
   - 找到 Pages 选项
   - Source 选择 `main branch`
   - 保存后等待部署（约 1-2 分钟）

4. **获得链接**
   - 格式：`https://adamlei.github.io/adamlei/`
   - 或自定义域名
